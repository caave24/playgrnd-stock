# playgrnd stock

A GitHub-based stock media gallery.

Put supported media directly in the repository root and push to `main`.

- Images move to `/static_images/`
- Videos move to `/videos/`
- Videos are also converted to GIF previews in `/static_images/`
- `index.html` is automatically regenerated
- Gallery images link directly to their GitHub raw URLs
- `grd.css` supplies the 12-column responsive grid

Supported images: PNG, JPG, JPEG, WebP, GIF, AVIF, BMP, TIFF.

Supported videos: MP4, WebM, MOV, M4V, AVI, MKV.

The generated gallery is between the `PLAYGRND-STOCK` start/end comments.
